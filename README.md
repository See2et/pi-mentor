# Pi Mentor

普段の Pi チャットで、目標・制約の整理から、論点・仮説の検討、本人の判断、実装・検証までを進める拡張です。フェーズの移動、論点の選択、仮説の確認、採否の判断は本人が操作し、AI は提案・記録を行います。採点や理解度スコアはありません。

## 読み込む

Pi 1.0.4 / Node 24 で確認しています。このリポジトリで実行してください。

```sh
pi --extension .
```

現在の Pi モデルと認証をそのまま使います。別プロバイダへの呼び出しや認証の変更は行いません。

## 使う

1. `/mentor` で開始し、目標・制約と論点を入力します。「現在の論点を選ぶ」で検討する論点を選びます。
2. メニューで段階を選び、通常のチャット、または「現在の位置から対話を始める」で相談します。論点の追加や段階の移動だけでは、推論は始まりません。
3. 仮説を作成・改訂し、批判や弁護を検討します。AI 下書きは、本人が内容を確認するまで現在仮説にはなりません。AI が整理した応答も本人の記録とは区別されます。
4. 「現在の仮説を判断する」で内容と未撤回の懸念を確認し、暫定採用・修正・保留を記録します。AI の合格判定は不要です。仮説がなくても保留でき、改訂後は旧版の判断を引き継がず、履歴を残します。

「記録を見る…」で詳細を閲覧し、「移動・その他…」で論点や段階の選択、目標の編集などを行います。ヒントはどの段階でも選べ、**今回の応答だけ**に適用されます。ヒントも通常の Pi 推論を開始します。

- `/mentor status`：全記録をチャットに表示。
- `/mentor pause`：通常チャットへ戻る。一時停止中は Mentor の指示を注入せず、AI の記録操作も拒否します。
- `/mentor resume`：再開。

メニューを Esc で閉じても記録は変わりません。閲覧画面の Enter は戻るだけで、確定は別操作です。メニューを開いている間に記録やセッションが変わった場合は保存を拒否するため、開き直してください。

## 実装・検証に進む

「移動・その他…」から「実装・検証」を選べます。まとめの完了は不要です。

1. `/mentor unitNew` で機能実装か仮説実験を選び、目的・設計参照・範囲・ID 付きの期待・非目標・検証計画を入力します。
2. 契約の内容を確認して保存し、`/mentor units` で単位を選び、メニューで実装開始を明示します。AI 下書きも `/mentor unit-draft` で本人が確認するまで現在契約にはなりません。
3. 通常の Pi ツールで実行します。AI に `mentor_status` の実観測ソースを参照して `mentor_record` の `unitEvidence` を提出させ、「証拠の検討」で期待 ID ごとの観測、コマンド・結果・参照、実対象／代替／未検証、限界・懸念を確認します。
4. 契約版・ソース・証拠を確認し、受け入れ／修正依頼／設計に戻る／保留を選びます。理由・留保も残せます。

テスト成功や理解度の試験は合格条件ではありません。証拠不足のままでも本人が判断できます。実験の受け入れは、設計や機能の採用を意味しません。

ソースの識別対象は、**Git 追跡ファイル（変更・削除を含む）と ignored でない未追跡ファイルの内容**です。自動コミットはしません。契約や内容が変わると、過去の証拠・受け入れは履歴に残り、現行扱いではなくなります。

ソースは status・メニュー・判断直前・Pi ツール境界で再観測します。Git 外、サブモジュール／特殊ファイル、ツール実行中など観測できない場合は鮮度不明です。最終確認時の一致を示すもので、原子的なスナップショットやライブ監視ではありません。ignored ファイル、リンク先の外部内容、外部サービス、依存環境の状態は保証対象外です。

## 保存と制限

**新規セッションでメニューだけを操作して終了すると、記録は残りません。** Pi は実際のユーザーまたはアシスタントのチャットメッセージがあるまで、新規セッションをディスクへ保存しません。最初の通常チャット後は、それ以前の Mentor 記録も保存されます。`--no-session` では常にメモリ内のみです。

記録は Pi のセッションエントリに保存し、現在の枝だけから復元します。再開・分岐・ツリー移動・再読み込みに追従し、旧 schema 1 の設計記録も履歴を保って読み込みます。破損・未対応データでは変更を止め、`/mentor` で確認付きのリセットを選べます。過去のエントリは削除しません。

モデルの記録ツールはフェーズ・論点選択・本人判断を変更できません。ただし、対話や批判の質はモデル次第です。通常の Pi ファイル操作ツールはそのまま使えるため、**書き込み禁止のサンドボックスではありません**。記録はセッションに平文で残るため、秘密情報は入力しないでください。
