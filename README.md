# Pi Mentor

普段の Pi チャットで、目標・制約の整理から、案の検討、本人の判断、実装・検証までを進める拡張です。AI が会話から候補と次の一手を整理し、本人が `/mentor` のカードで選んだときだけ進みます。普通の返事や相づちでは進まず、採点や理解度スコアもありません。

## 読み込む

Pi 1.0.4 / Node 24 で確認しています。このリポジトリで実行してください。

```sh
pi --extension .
```

現在の Pi モデルと認証をそのまま使います。別プロバイダへの呼び出しや認証の変更は行いません。

## 使う

1. `/mentor` で開始し、普通のチャットで作りたいものや困っていることを相談します。AI は必要に応じてヒントや例、批判を出し、現在の候補と未解決事項を整理します。
2. `/mentor` を開くと「現在の相談」「候補」「選ぶと何が確定するか」と、次の一手を表示します。候補がまだなければ「次の一手を一緒に整理する」で相談を依頼できます。
3. 「議論を続ける」は何も変えずに閉じます。「この案を批判・弁護してみる」などの一手を選ぶと、必要な記録と相談位置をまとめて変更します。仮説の登録や版の選択を別に行う必要はありません。選択自体では推論を始めず、その位置から普段のチャットを続けます。

カードの詳細は PgUp/PgDn・Home/End で読めます。↑↓ で操作を選び、Enter で実行、Esc で取消です。最初の選択は常に「議論を続ける」です。未解決事項があっても、本人が留保して進めます。AI の合格判定は不要です。

「その他…」には今回だけのヒント、理由・留保の編集、案の練り直し、設計への戻り、履歴、以前の相談への切替、一時停止があります。ヒントと「次の一手を整理する」は通常の Pi 推論を依頼します。ヒントは**今回の応答だけ**に適用されます。

- `/mentor status`：全記録をチャットに表示。
- `/mentor pause`：通常チャットへ戻る。一時停止中は Mentor の指示を注入せず、AI の記録操作も拒否します。
- `/mentor resume`：再開。

Esc で閉じても記録は変わりません。履歴の閲覧画面の Enter は戻るだけです。候補の作成後やカードを開いている間に記録・コード・セッションが変わった場合は、古い内容での確定を拒否します。候補を整理し直してください。

以前の手動操作は `/mentor advanced` と既存のショートカットに残していますが、通常の導線では使いません。

## 実装・検証に進む

案を検討し、「この方向を暫定採用し、範囲を考える」を選んでも、実装はまだ許可されません。AI と目的・範囲・期待・非目標・検証計画を具体化し、カードの正確な内容で「この範囲で実装・検証を始める」を選ぶと、その範囲だけの実装を許可します。仮説を確かめる実験も、設計採用とは別の範囲として選べます。

通常の Pi ツールで実装・検証し、AI が実観測ソースに紐づく証拠を記録します。「この結果を確かめる」で実装を止め、期待ごとの観測、参照・コマンド・結果、実対象／代替／未検証、限界を相談します。その後、留保込みの受け入れ、同じ範囲の修正開始、設計への戻り、保留を本人が選びます。受け入れても次の作業は始まりません。

テスト成功や理解度の試験は合格条件ではありません。証拠不足のままでも本人が判断できます。実験の受け入れは、設計や機能の採用を意味しません。

ソースの識別対象は、**Git 追跡ファイル（変更・削除を含む）と ignored でない未追跡ファイルの内容**です。自動コミットはしません。契約や内容が変わると、過去の証拠・受け入れは履歴に残り、現行扱いではなくなります。

ソースは status・メニュー・判断直前・Pi ツール境界で再観測します。Git 外、サブモジュール／特殊ファイル、ツール実行中など観測できない場合は鮮度不明です。最終確認時の一致を示すもので、原子的なスナップショットやライブ監視ではありません。ignored ファイル、リンク先の外部内容、外部サービス、依存環境の状態は保証対象外です。

## 保存と制限

**新規セッションでメニューだけを操作して終了すると、記録は残りません。** Pi は実際のユーザーまたはアシスタントのチャットメッセージがあるまで、新規セッションをディスクへ保存しません。最初の通常チャット後は、それ以前の Mentor 記録も保存されます。`--no-session` では常にメモリ内のみです。

記録は Pi のセッションエントリに保存し、現在の枝だけから復元します。再開・分岐・ツリー移動・再読み込みに追従し、旧 schema 1 の設計記録も履歴を保って読み込みます。破損・未対応データでは変更を止め、`/mentor` で確認付きのリセットを選べます。過去のエントリは削除しません。

モデルの記録ツールはフェーズ・論点選択・本人判断を変更できません。ただし、対話や批判の質はモデル次第です。通常の Pi ファイル操作ツールはそのまま使えるため、**書き込み禁止のサンドボックスではありません**。記録はセッションに平文で残るため、秘密情報は入力しないでください。
